## Traps

- **`_site/` lies.** This session patched the built `index.html` in place
  — swapping JS blocks and recomputing the topics payload — to preview
  without a 13-minute build. It works, and it fooled me once: a preview
  came up as skeletons because a function did not make it across, and the
  bug was in the patch, not the code. Rebuild before believing anything.
- **Firefox caches CSS across headless runs.** Every screenshot in this
  session used a fresh port for that reason. Keep doing it.
- **A parallel session was editing the same files.** ADRs `0013`–`0016`
  and their code appeared mid-conversation. Check `git status` before
  assuming the tree is yours, and never restore files wholesale from a
  snapshot without checking what has landed since.
- **Duration data is dirty.** 22 item spans exceed three hours and four
  run about 6.9 days. The new ranking ignores anything over three hours,
  which is a guard and not a fix — `TODO.md` item 13.
- Do not re-derive the coverage ceiling: only ~20% of card rows have a
  written Description and 22% have a chip, because that is how far
  summarize runs have got. It is a coverage problem, not a rendering one.
