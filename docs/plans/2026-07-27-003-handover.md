## Traps

- **Do not "fix" a continuation bullet in code.** It was tried this
  session and reverted. Joining "This is a public hearing, not final
  approval" to the bullet above it welded a caveat onto an unrelated
  fact, and the pair asserted something neither bullet said — the judge
  scored that item 1 for faithfulness. A string join cannot tell a
  chopped sentence from a separate thought. The reason is written beside
  `CONTINUATION_OPENERS` in `item_categorizer.py`; read it before
  reaching for the same idea.
- **The two description rules pull against each other.** Push harder on
  "no continuations" and the model collapses to one bullet that echoes
  the title (2/24). Push back on that and the continuations return
  (5/24). The wording that balances them is in the prompt now; change one
  rule and re-measure both, not just the one you touched.
- **The judge's mean is noisy** — 4.12 to 4.58 across five runs of this
  session's code. **Do not conclude a change worked from one run.** The
  previous session reported the eval fixed on a single 4.42 and CI went
  red on the next push.
- **The continuation gate is a share (10%), not zero.** Deliberate: no
  prompt wording reaches 0/24 reliably, and a gate that reddens on one
  unlucky sample is a gate people learn to ignore. The count prints on
  every run whether it fails or not.
- **Coverage is still the real ceiling, not format.** 956 of 1,302
  rendered card rows have no chips at all. That is how far summarize runs
  have got — not a rendering bug. Do not re-derive it.
- **Firefox caches CSS across headless runs.** Use a fresh port and a
  fresh profile (`mktemp -d`) every screenshot. This session did.
- **`gh` is not installed.** Use the GitHub REST API via `curl` for run
  status. Job *logs* need auth and 403; reproduce failures locally
  instead, which works because `.env` has the key.
- The eval's model is `gemini-2.5-flash` (`GEMINI_MODEL`). Do not guess a
  model name; `gemini-2.0-flash` is retired and 404s.
