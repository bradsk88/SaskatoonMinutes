## Traps

- **Never judge the A/B by its labels.** `blind_orders` re-randomizes A/B
  per item. Judge per item, unblind, then aggregate. Judges that reason
  across items produce confident nonsense.
- **`pairs.md` is 440k characters at 22 items** — too big for one judge.
  Split it into ~110k-character chunks of whole items and give each
  chunk three judges. The splitter used this session is disposable; the
  rule (whole items, never split an item) is not.
- **Judges must not read the repo.** Give them the chunk path and forbid
  other files, or they will find `key.json`.
- **`ab_cleanup.py` refuses to re-clean** on a cache miss, deliberately.
  Run `eval_chips.py` first.
- **The roster metric flags, never scores.** `Meewasin ← "Me was in"` and
  `Remai Modern ← "Remly"` have the same signature and edit distance
  prefers the fabrication. A person rules on each.
- **The name-density counter in `add_eval_fixture.py` is loose** — it also
  counts `April`, `AM`, `ARO`. Fine for ranking, wrong as a name count.
