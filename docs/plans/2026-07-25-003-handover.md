### `scripts/add_eval_fixture.py` (new)

    python scripts/add_eval_fixture.py --tab public-hearing --date 2026-05-27
    python scripts/add_eval_fixture.py --meeting <id> --items 5 --dry-run

- Ranks eligible items by **name density**: distinct capitalized tokens
  in the item's *raw* slice that are absent from `_SASKATOON_NAMES`.
  That is the population cleanup acts on.
- Sentence-initial capitals excluded — the transcriber capitalizes every
  sentence, so counting those would rank by verbosity.
- Prints the full ranking each run, passovers included.
- Excludes items with no transcript slice (both A/B arms identical).
- Slices with `_slice_transcript`, so fixtures are byte-identical to what
  production would hand the extractor.
- Refuses a meeting with no cached transcript; refuses to overwrite
  without `--force`.

## Do this next — U9 step 3

1. **`scripts/eval_chips.py --snapshot`.** This is the first real spend:
   it cleans ~200k characters of new transcript. It is also the spend
   the A/B exists to price, so it is the right spend.
   - `--check` thresholds (`MIN_SOFT_COVERAGE`, `MAX_TITLE_ECHO`) were
     tuned at n=11. Tripping them at n=24 is a threshold problem, not a
     regression.
2. **Re-run `ab_cleanup.py` + blind judges** at the new n.
3. **Build the roster-attractor report** — the primary metric, still
   unwritten: entries of `_SASKATOON_NAMES` appearing in a summary but in
   neither the official text nor the raw transcript. The raw arm should
   score 0 by construction; if it doesn't, the harness is wrong, not
   cleanup.
   - **Flag, do not auto-score.** `Meewasin ← "Me was in"` (good) and
     `Remai Modern ← "Remly"` (bad) have the same signature, and edit
     distance scores the known failure as a success. A human rules on
     each.
4. **Apply the pre-registered decision rule.** Cleanup survives only if
   good corrections outnumber bad substitutions **and** blind judges give
   clean ≥ raw. A tie deletes it. The rule was fixed before the data and
   must not be renegotiated after it.
