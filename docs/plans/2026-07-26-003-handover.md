## Traps

- **Do not trust a small slice.** The 4-meeting smoke build looked
  perfect while a third of the real corpus had mangled body names. Both
  bodies in the slice happened to have single-line headings. Sweep all
  310 built pages with a script before believing a parser change.
- **Firefox caches CSS across headless runs.** A stylesheet edit
  appeared to have no effect; it had. Serve from a **new port** to bust
  it, or you will "fix" a bug twice.
- **`--window-size` gives you the viewport only**, not a full-page
  capture. That is a feature for judging the first screen; it is a trap
  if you think you are seeing the whole page.
- Do not guess at eSCRIBE markup. Fetch one real page with `curl` and
  look. Every wrong guess this session came from reasoning about HTML
  instead of reading it. The fixture `agenda_abc-001.html` is synthetic
  and does not resemble the real thing closely enough.
- `build_site` opens `GitBranchCache`, which pushes on exit **only if
  the run saved something**. A build only reads, so it does not push.
  Do not "fix" this.
- I burned Brad's time by continuing to work after he asked to move to a
  new session. When he says he is stepping away, write the handover.
