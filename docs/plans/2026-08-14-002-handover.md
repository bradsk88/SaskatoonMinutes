## Traps

- **Detection windows differ between paths.** Build pages run
  `correct_timestamps` before `mark_jointly_heard`; the summarize path
  detects on raw eSCRIBE bookmarks. The union of raw windows still
  contains everything either raw bookmark covered, so the summarizer
  can only gain transcript — but a pair detected on corrected windows
  could in principle not group on raw ones (or vice versa). All three
  known pairs group regardless; worth rechecking if a new pair appears.
- **`_site/` is stale** (no rosters at all). Fleet measurement used the
  live site: index `preloaded-topics` for speaker counts, then only
  the 101 pages with speakers. Grep-able per-page:
  `<script[^>]*id="preloaded-meeting"[^>]*>` (attribute order varies).
- **Whisper garblings mean name-probes undercount.** "Em Ironstar" is
  "Emma Armstrong" in the transcript; "Daniel Macdonald" appears only
  as "McDonald" (8×, some being Councillor Macdonald). The slice check
  must probe what Whisper wrote, not the roster.
- The fetched page snapshots predate the phonetic-fallback deploy, so
  Em Ironstar has no stamp in `/tmp` copies — the live data is newer.
